# Job Review & Posting Analysis

기업 리뷰 텍스트를 전처리·분석·점수화하고, 채용공고 데이터와 결합하여 구직자의 지원 판단을 돕는 데이터 기반 취업 지원 서비스 프로젝트입니다.

> 본 프로젝트는 데이터 분석 부트캠프 과정에서 수행한 팀 프로젝트이며, 본 저장소는 제가 담당한 **기업 리뷰 분석·점수화·통합 테이블 구축 파트**를 중심으로 재구성했습니다.

## 1. 프로젝트 개요

채용공고 데이터, 기업 리뷰 데이터, 사용자 입력 정보를 활용해 구직자의 지원 판단을 돕는 데이터 기반 취업 지원 서비스 프로젝트입니다.

기업 리뷰는 구직자가 기업을 판단할 때 중요한 정보원이지만, 대부분 비정형 텍스트 형태로 존재하기 때문에 기업별 비교나 추천 로직에 직접 활용하기 어렵습니다.

이 프로젝트에서는 기업 리뷰 텍스트를 분석 가능한 정량 지표로 변환하고, 채용공고 데이터와 결합하여 지원 판단에 활용 가능한 통합 분석 테이블을 구축했습니다.

---

## 2. 문제 정의

구직자는 채용공고, 기업 리뷰, 직무 요구사항, 기업문화, 복지, 안정성 등을 각각 따로 확인해야 하며, 이 과정에서 지원 판단 비용이 높습니다.

특히 기업 리뷰는 중요한 정보원이지만 대부분 비정형 텍스트이기 때문에, 원문을 그대로는 기업별 비교나 추천 서비스에 활용하기 어렵습니다.

따라서 본 프로젝트에서는 리뷰 텍스트를 카테고리별 긍정·부정 신호로 구조화하고, 기업별 점수로 변환하는 분석 과정을 설계했습니다.

## 3. 사용 데이터

- 기업 리뷰 데이터
- 채용공고 데이터
- 기업명 및 기업 식별 정보
- 직무/스킬 관련 데이터

- 리뷰 카테고리 및 감성 사전

> 본 저장소에는 공개 가능한 범위의 분석 흐름, 결과 요약, Notion 상세 페이지 링크를 중심으로 정리했습니다.

- 기업 리뷰 데이터 전처리
- 복합명사 사전, 표준화 사전, 카테고리 사전 작성

- 리뷰 텍스트 형태소 분석 및 감성분석 처리

- 기업별 리뷰 점수화 로직 설계
- 채용공고 점수와 리뷰 점수를 결합한 통합 분석 테이블 구축
- 최종 서비스 추천 로직에 활용 가능한 데이터셋 구성

## 5. 분석 과정

### 5.1 리뷰 데이터 전처리

- 결측치 및 중복값 정리
- 기업명 표준화
- 분석에 불필요한 텍스트 제거
- 형태소 분석을 위한 텍스트 정제

### 5.2 사전 구축

- 복합명사 사전
- 표준화 사전
- 카테고리 사전
- 불용어 사전

리뷰 텍스트에서 동일한 의미의 표현이 다르게 처리되지 않도록 사전을 구성하고, 기업 판단에 필요한 항목별로 키워드를 분류했습니다.

### 5.3 감성분석 및 점수화

- 리뷰 텍스트에서 긍정·부정 신호 추출
- 복지, 성장성, 안정성, 조직문화 등 카테고리별 신호 집계
- 기업별 리뷰 점수 산출
- 채용공고 기반 점수와 결합

### 5.4 통합 테이블 구축

리뷰 기반 점수와 채용공고 기반 점수를 결합하여 기업·직무별 종합 판단에 활용 가능한 통합 분석 테이블을 구축했습니다.
