# 타이타닉 생존 예측과 주요 특성 해석

**작성자:** bolly0809-coder

## 요약 (Executive Summary)

공개 정답이 있는 승객 **891명**을 대상으로 생존 여부를 예측하고, 모델의 성능과 예측 근거를 함께 분석했다. 데이터 품질 점검·파생변수 생성에서 출발해 11개 분류모형 비교·튜닝, 과적합 진단, RandomForest 변수 축소 및 SHAP을 수행했다.

- **분류 성능:** 내부 검증 179건에서 튜닝 KNN이 **F1 0.773·정확도 83.2%**로 비교표 1위였다.
- **확률 예측:** KNN의 LogLoss는 1.710, 7변수 튜닝 RandomForest는 0.433이었다. 분류 성능과 확률 예측 품질의 순위가 달랐다.
- **변수 축소:** RandomForest 입력을 7개에서 5개로 줄이면 F1이 0.7344에서 0.7132로 낮아졌다. 간소화를 성능 개선으로 채택하지 않았다.
- **예측 근거:** 축소 RandomForest의 SHAP에서 호칭의 기여가 가장 컸고, 객실 등급·요금·연령·객실 번호 기록 유무도 활용되었다.

**상세 분석:** [단일 노트북 — 실행 결과·시각화·단계별 해석](titanic-survival-analysis.ipynb)

## 분석 목적과 데이터

이 프로젝트는 승객 특성별 생존율의 차이, 동일한 평가 조건에서의 모델 성능, 변수 축소의 효과를 분석하고 SHAP으로 예측 근거를 해석했다.

`jussam.load_data("titanic")`로 로드한 자료 중 PassengerId 1~891을 사용했다. 정답 비공개 테스트 구간에 해당하는 나머지 418건은 학습·평가에서 제외했다. 생존은 342명(38.4%), 사망은 549명(61.6%)이며 분석 대상의 중복 행은 0건이었다.

모델 입력은 **Title·Pclass·Embarked·HasCabin·Age·Fare·FamilySize**의 7개다.

| 파생변수 | 구성 | 해석상 주의점 |
|---|---|---|
| Title | 이름의 17종 호칭을 Mr·Miss·Mrs·Master·Officer로 통합 | 성별·연령과 정보를 공유하지만 동일하지 않음 |
| FamilySize | SibSp + Parch + 1 | 본인을 포함한 가족 규모; 1은 단독 승객 |
| HasCabin | Cabin 값의 기록 유무 | 실제 객실 소유·존재 여부를 직접 측정한 값은 아님 |

Age의 결측은 177건(19.9%)이었다. EDA에서는 중앙값 28세로 대체했다. **EDA의 Embarked는 대체 함수 호출 이후에도 결측 2건이 남아 승선항 분석을 유효 889건 기준으로 해석했다.** 모델링은 EDA 작업본과 분리하여 원자료에서 입력을 만들고, 파이프라인의 중앙값·최빈값 대체로 처리했다.

## 분석 과정

1. **품질 점검·파생변수:** 라벨 사용 범위, 중복·결측·자료형을 확인하고 호칭·가족 규모·객실 정보 기록 유무를 구성했다.
2. **EDA:** 단변량 분포, 생존 집단 간 수치형 분포 차이, 범주별 생존율 및 공선성을 검토했다.
3. **베이스라인 비교:** 선형·거리 기반·트리·앙상블 계열 11개 분류모형을 동일한 내부 검증셋에서 비교했다.
4. **튜닝:** 훈련 데이터의 5-fold GridSearchCV에서 F1을 기준으로 모델별 설정을 선택했다.
5. **진단·축소:** DecisionTree·RandomForest의 훈련/CV/검증 지표를 진단하고, RandomForest 누적 중요도 90% 기준으로 변수를 줄여 비교했다.
6. **SHAP:** 축소 모델의 실제 입력과 연결하여 생존 클래스 예측의 기여 방향과 분포를 해석했다.

분할은 `random_state=3217`, 훈련 712건·내부 검증 179건, `stratify=target`으로 설정했다. 수치형 중앙값·범주형 최빈값 대체와 모델별 스케일링·인코딩은 파이프라인 안에서 수행하며, 튜닝 시 각 CV 훈련 fold에서 다시 학습했다. 별도 리샘플링이나 Fare 로그변환은 적용하지 않았다.

## 핵심 결과

### 1. 호칭·성별·등급과 생존율의 관계

| 특성 | 주요 관찰 | 해석 |
|---|---|---|
| 성별 | 여성 74.2%, 남성 18.9% 생존 | 표본 내 생존율 차이가 큼; Cramer's V 0.541 |
| 호칭 | Mrs 79.7%, Miss 70.3%, Master 57.5%, Officer 27.8%, Mr 15.8% | V 0.572; 성별·연령 등과 정보가 겹침 |
| 객실 등급 | 1등급 63.0%, 2등급 47.3%, 3등급 24.2% | V 0.340; 등급별 생존율 차이 관찰 |
| 승선항 | C 55.4%, Q 39.0%, S 33.7% | V 0.173; 결측 제외 889건 기준 |
| 가족 규모 | 1명 30.4%, 4명 72.4%, 5명 20.0%, 6명 13.6% | 단순 증가 관계가 아니며 큰 가족의 표본 수는 작음 |

네 범주형 변수의 카이제곱 검정은 모두 p<0.001이었다. 그러나 연관성이 실제 구조 순서나 개인 행동의 인과효과를 뜻하지는 않는다. Officer는 18명, 가족 규모 4명·5명·6명은 각각 29명·15명·22명으로 작은 집단의 비율을 일반화하는 데 주의했다.

수치형 변수의 Mann–Whitney U 양측검정에서 Age는 p=0.270으로 유의한 분포 차이를 발견하지 못했고, SibSp는 p=0.008, Parch·Fare·FamilySize는 p<0.001이었다. 이는 평균 차이 자체의 검정이 아니며, Age의 결과를 연령이 무관하다는 증거로 해석하지 않았다.

### 2. 모델 비교: 높은 F1과 좋은 확률 예측은 다르다

아래는 동일한 내부 검증 179건의 지표다. KNN·L1 로지스틱 회귀·CatBoost·7변수 RandomForest는 11개 모델 튜닝 비교표의 결과이며, 5변수 RandomForest는 후속 축소 실험이다.

| 모델 | Accuracy | Precision | Recall | F1 | ROC-AUC | LogLoss |
|---|---:|---:|---:|---:|---:|---:|
| **KNN, 튜닝** | **0.832** | **0.810** | **0.739** | **0.773** | 0.863 | 1.710 |
| L1 로지스틱 회귀, 튜닝 | 0.816 | 0.781 | 0.725 | 0.752 | 0.837 | 0.464 |
| CatBoost, 튜닝 | 0.810 | 0.787 | 0.696 | 0.738 | 0.848 | 0.478 |
| RandomForest 7변수, 튜닝 | 0.810 | 0.797 | 0.681 | 0.734 | 0.860 | **0.433** |
| RandomForest 5변수, 축소 후 튜닝 | 0.793 | 0.767 | 0.667 | 0.713 | 0.845 | 0.455 |

KNN은 F1에서 가장 높았지만, 확률 예측 품질을 평가하는 LogLoss에서는 불리했다. 7변수 RandomForest의 LogLoss 0.433은 튜닝 비교표의 확률 출력 가능 모델 중 가장 낮았다. 따라서 **F1 기준 최고 모델은 KNN으로, 후속 변수 중요도·축소·SHAP 분석 모델은 RandomForest로 구분**했다. RandomForest를 전체 최고 성능 모델로 제시하지 않았다.

튜닝이 모든 지표를 높인 것도 아니다. CatBoost는 F1 0.708→0.738로 개선됐지만 LogLoss는 0.435→0.478로 악화됐다. LightGBM도 F1 0.769→0.729로 하락했다. CV에서 선택한 설정이 내부 검증셋의 성능까지 반드시 높이는 것은 아니라는 점을 확인했다.

### 3. 변수 축소: 간소화했지만 성능은 유지하지 못했다

7변수 RandomForest의 불순도 감소 중요도(MDI)는 Title 약 51.9%, Fare 12.5%, Pclass 10.5%, Age 8.1%, HasCabin 7.2%, FamilySize 6.6%, Embarked 3.1% 순이었다. 누적 90% 기준으로 **Title·Fare·Pclass·Age·HasCabin**을 선택했으며 누적 비중은 90.32%였다.

그러나 7개에서 5개로 줄이자 내부 검증 F1은 **0.7344→0.7132**, ROC-AUC는 **0.8598→0.8455**, 정확도는 **81.01%→79.33%**로 낮아졌다. CV F1도 0.7635→0.7560으로 감소했다. 두 모델의 선택 설정은 모두 트리 300개, 최소 잎 표본 5개였다.

중요도의 90%를 남겼다고 성능의 90%나 동일한 성능이 보장되는 것은 아니다. **변수 축소를 성능 개선으로 채택하지 않았으며, RandomForest 계열에서는 성능 보존 관점에서 7개 입력을 유지하는 판단이 타당하다.** 5변수 모델의 SHAP은 축소 실험에 대한 해석 결과로 남겼다.

### 4. SHAP: 어떤 특성이 생존 예측을 움직였는가

5변수 RandomForest를 대상으로 훈련 표본 200건을 설명했다. 원핫 인코딩 후 12개 열을 사용하며, 생존 클래스 1의 기준값은 약 0.3837, SHAP 단위는 확률이다.

- **Mr 호칭:** mean|SHAP| 0.1406으로 가장 컸다. Mr 해당 관측치는 주로 음의 기여를 보였다. 평균 절대 기여 약 14.06%p는 모든 개인에게 동일한 효과나 인과효과를 뜻하지 않는다.
- **Miss·Mrs 호칭:** 해당 관측치는 주로 양의 기여를 보였다. 성별·연령과 공유하는 정보를 고려해야 한다.
- **3등급:** 주로 음의 기여를 보였으며 객실 등급별 표본 생존율 차이와 함께 해석했다.
- **요금·연령:** 높은 요금 관측치는 대체로 양의 기여, 어린 연령 일부는 양의 기여, 고연령 관측치는 주로 음의 기여를 보였다. 하지만 단조관계가 아니며 연령에는 결측 대체의 영향도 포함된다.
- **객실 정보 기록:** 기록이 있는 관측치는 주로 양의 기여를 보였다. 기록 여부 자체가 생존의 원인이라고 해석하지 않았다.

SHAP 출력의 평균 `방향` 문구를 개별 특성값의 효과로 오독하지 않았다. 예컨대 Mr 더미의 평균 방향이 '증가'로 표시되어도, 실제 Mr 해당 점들은 음의 영역에 분포했다. 값과 SHAP 분포를 함께 확인했으며 이 설명을 다른 모델에 그대로 적용하지 않았다.

## 결론과 한계

이 프로젝트의 핵심은 최고 점수만 제시하는 것이 아니라 **분류 성능·확률 품질·간소화의 손실·예측 설명의 범위를 구분한 것**이다. 복잡한 모델이 항상 더 좋은 것은 아니었고, 튜닝과 변수 축소도 자동적인 성능 향상을 보장하지 않았다.

- **평가 범위:** 동일한 내부 검증셋을 반복 참조했으므로 독립 최종 테스트 점수나 Kaggle 비공개 테스트 점수로 표현하지 않는다. 튜닝 후 진단 CV는 중첩 교차검증이 아니며, 변수 선택 후 CV도 선택 절차 전체를 독립적으로 검증한 값은 아니다.
- **표본·결측:** 공개 학습 표본 891건, Age 177건 대체, 희소 호칭과 큰 가족 집단이라는 한계가 있다. EDA의 승선항 분석은 결측이 잔존한 889건 기준이다. 모델링은 별도 파이프라인으로 결측을 처리했다.
- **해석 범위:** MDI는 정보 중복과 분할 후보 수의 영향을 받으며, SHAP은 훈련 표본에서 학습된 모델의 예측 설명이다. 역사적 생존 원인·개입 효과나 Title의 독립적인 추가 성능을 입증하지 않는다.
