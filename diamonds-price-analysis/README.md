## 요약 (Executive Summary)

- **데이터:** [Diamonds — Kaggle](https://www.kaggle.com/datasets/shivam2503/diamonds)
- **규모:** 원본 53,940개 관측치 × 10개 변수 → 중복 146행 제거 후 53,794개 관측치
- **문제 유형:** 가격 설명 및 예측모형 비교(회귀)

> 다이아몬드의 중량(`carat`)과 컷·색상·투명도 등급이 가격(`price`)과 어떤 관계가 있는지 분석했다.
> 품질 점검과 EDA 후 로그 변환·이상치 대체·VIF·스케일링을 누적한 모형과, 크기 축의 대표로 `carat`을 남긴 도메인 모형 등 **9개 모형**을 비교했다.
> **도메인 변수 선택 + 로그 변환 + 이상치 대체 모형**을 최종 채택했다. 독립변수 18개, 원본 가격 척도 R² 약 **0.960**, RMSE **796.879달러**, MAE **402.916달러**였다.
> 기계적 전처리의 최고 모형보다 **변수는 3개 줄고 RMSE는 약 4.22% 낮았다.** 전체 기준선 대비 RMSE 감소율은 약 29.57%였다.
> 중량 계수는 약 1.884로, 다른 조건을 통제했을 때 중량 1% 증가와 약 1.88%의 예측 가격 차이가 관련되었다. 품질 등급의 조건부 가격 차이도 확인했다.
> **성능 수치는 적합에 사용한 표본 내 결과다.** 별도 테스트셋·교차검증 성능이나 인과효과로 해석하지 않는다.

**상세 분석 노트북:** [Diamonds 가격 분석 — 전체 분석과 실행 결과](diamonds-price-analysis.ipynb)

## 회고

- **이번 분석에서 정리한 기법:** 전처리를 하나씩 누적한 체크포인트로 성능 변화를 비교하고, VIF에 의한 기계적 변수 제거와 `carat`을 대표 변수로 남기는 도메인 선택을 같은 표에서 비교했다. 변수 수와 오차를 함께 보았으며, 최종 선택은 출력된 비교 규칙을 따랐다.
- **점검한 지점과 해석 방법:**
  - ① 실제 최종 변환은 `log(price)`와 `log(carat)`이었다. 이전 참고 설명의 `log1p(price)`와 수치를 현재 실행 결과로 바로잡았다.
  - ② 비교표의 Gap(%)는 최저 RMSE를 분모로 한 격차다. 이전 모형 대비 감소율과 구분하여, 기계적 최고 모형 대비 개선을 약 4.22%로 계산했다.
  - ③ 품질 등급별 단순 평균과 중량을 통제한 회귀 결과를 구분했다. 더미 번호 자체에 연속적인 의미를 부여하지 않고 기준 범주 대비 차이로 해석했다.
- **다음 분석에서 보완할 점:**
  - 표본 내 적합값으로 모델을 비교했으므로 독립적인 평가셋 또는 교차검증을 통한 일반화 검증이 필요하다.
  - RESET F = 923.615, K–S = 0.018, BP F = 76.125에서 각각 p < .001이었다. HC3는 표준오차를 보정하지만 비선형성·이분산 자체를 해소하지 않는다.
  - 0mm·극단 치수의 원자료 확인과 별도 오류값 정제가 필요하다. IQR 경계값 대체를 오류값 검증 완료와 동일시하지 않는다. 최종 모형에는 `x`·`y`·`z`를 사용하지 않았다.
  - DW는 행 순서에 의존한다. 횡단면이라는 이유로 독립성을 가정하거나 행을 섞어 해결됐다고 판단하지 않고, 수집 구조를 확인해야 한다.
  - 결과를 현재 다이아몬드 시장 전체의 시세나 개입에 따른 가격 변화로 일반화하지 않는다.
