# Seoul Isolation Risk Analysis

서울시 행정동 단위 공공데이터와 서울 빅데이터 캠퍼스의 생활인구·생활이동 데이터를 결합하여 생애주기별 사회적 고립 위험지역을 분석한 프로젝트입니다.

> 본 프로젝트는 아이티윌 데이터 분석 부트캠프 과정에서 수행한 팀 프로젝트이며, 데이터 수집, 전처리, 분석, 시각화, 보고서 작성까지 전 과정에 참여했습니다. 특히 외부 공공데이터 결합과 시각화 파트를 주도했습니다.

## 1. 프로젝트 개요

서울시 행정동 단위 공공데이터와 서울 빅데이터 캠퍼스의 생활인구·생활이동 데이터를 결합하여 청년층, 중장년층, 노년층의 사회적 고립 위험도를 분석한 프로젝트입니다.

생애주기별 위험 요인을 복합위험지수로 구조화하고, 고위험 행정동과 정책 개입 우선순위를 도출했습니다.

## 2. 문제 정의

사회적 고립 위험은 단일 지표만으로 판단하기 어렵습니다.

1인가구, 독거노인, 생활인구, 이동성, 교통 접근성, 복지시설, 의료시설, 취약계층 분포 등 다양한 요인을 함께 고려해야 실제 정책 개입이 필요한 지역을 도출할 수 있습니다.

본 프로젝트에서는 서울시 행정동 단위로 여러 데이터를 결합해 생애주기별 고립 위험을 정량화했습니다.

## 3. 사용 데이터

- B040 서울시 집계구단위 내외국인 생활인구
- B076 서울시 행정동별 내국인 KT 생활이동 데이터
- 행정동별 기초생활수급자/차상위계층 데이터
- 국민기초생활보장수급자 및 등록장애인 데이터
- 서울 행정동별·연령별 독거노인 수 데이터
- 서울 행정동별 1세 단위 연령대별 1인세대수 데이터
- 지하철역/버스정류장 위치 데이터
- 서울시 노인여가복지시설 목록
- 서울시 노인의료복지시설 목록
- 서울시 경로당 현황
- 전국 병원·의원·종합병원 위치 및 좌표 데이터
- 전국 행정동 경계 SHP 파일

> 일부 원본 데이터는 서울 빅데이터 캠퍼스 자료 및 외부 공공데이터를 포함하므로, 본 저장소에는 샘플 데이터와 분석 흐름, 결과 이미지 중심으로 정리할 예정입니다.

## 4. 담당 역할

- 분석 주제 구체화 및 지표 후보 검토
- 외부 공공데이터 수집
- 빅데이터 캠퍼스 반출 데이터와 외부데이터 결합
- 데이터 전처리 및 행정동 단위 병합
- 생애주기별 위험지표 설계
- 청년층·중장년층·노년층별 위험도 분석
- 시각화 자료 제작
- 분석 결과 해석 및 보고서 작성
- 발표 자료 구성

## 5. 분석 과정

### 5.1 데이터 수집 및 병합

생활인구, 생활이동, 취약계층, 교통, 복지·의료 인프라 데이터를 수집하고 행정동 단위로 병합했습니다.

### 5.2 생애주기별 위험지표 설계

청년층, 중장년층, 노년층의 생활 조건과 고립 위험 요인이 다르다고 보고, 연령층별 위험지표를 설계했습니다.

### 5.3 복합위험지수 산출

지표 간 단위 차이를 보정하기 위해 표준화 과정을 적용하고, 지표별 가중치를 반영해 행정동별 복합위험지수를 산출했습니다.

### 5.4 고위험 지역 도출

생애주기별 고립 위험도가 높은 행정동을 도출하고, 각 지역의 위험 요인을 해석했습니다.

### 5.5 시각화 및 검증

행정동별 위험지수 분포, 연령층별 고위험 지역, 인프라 결핍 요인을 시각화했습니다.  
기초생활수급자 비율과 위험지수 간 관계를 확인하여 지표 해석 가능성을 점검했습니다.

## 6. 주요 시각화

- 복합위험지수 지표 구성 및 가중치 시각화
- 서울시 25개 자치구 연령대별 평균 위험지수 비교
- 행정동 고립유형 분류 도넛차트
- 인프라 결핍 분포 가로막대그래프
- 청년층·중장년층·노년층별 행정동 고립 위험지수 분포
- 복합 최고위험 행정동 TOP9 연령대별 위험지수 히트맵
- 기초생활수급자 비율과 위험지수 정합성 확인용 교차검증 스캐터플롯
- 가리봉동 생애주기별 고립 위험지수 적용 예시 그래프

## 7. 주요 결과

- 다양한 출처의 공공데이터를 행정동 단위로 결합하여 분석 가능한 데이터셋을 구축했습니다.
- 사회적 고립이라는 추상적 문제를 생애주기별 복합위험지수로 구조화했습니다.
- 청년층, 중장년층, 노년층별로 고립 위험의 원인과 우선 개입 지역이 다를 수 있음을 도출했습니다.
- 분석 결과를 지도 시각화와 정책 제안으로 연결했습니다.

## 10. 한계 및 개선 방향

- 일부 지표는 사회적 고립을 직접 측정한 데이터가 아니라 대체 지표로 활용되었기 때문에 해석상 한계가 있습니다.
- 실제 복지 서비스 이용 데이터, 상담 데이터, 장기 시계열 데이터가 결합되면 위험도 분석의 정확도를 높일 수 있습니다.
- 대시보드 형태로 고도화하면 정책 담당자가 지역별 위험 요인과 우선순위를 지속적으로 모니터링할 수 있습니다.
