# Commerce / Content / Ad Performance Analysis

커머스 또는 콘텐츠 데이터를 활용해 상품/콘텐츠 성과 지표를 정의하고, 카테고리·가격·리뷰·반응 데이터 기반의 성과 차이를 분석하는 개인 프로젝트입니다.

> 본 프로젝트는 데이터 분석가 지원을 위한 개인 미니 프로젝트로 준비 예정입니다.  
> 인라이플, 믹순, 미리디, 딥다이브, 나이키 리테일 등 커머스·콘텐츠·광고 성과 분석 직무에 대응하기 위한 포트폴리오로 구성할 예정입니다.

## 1. 프로젝트 목표

커머스 또는 콘텐츠 데이터를 활용해 상품/콘텐츠의 성과를 비교하고, 성과 차이에 영향을 줄 수 있는 요인을 분석합니다.

단순 랭킹이나 평점 비교가 아니라, 카테고리·가격·리뷰·댓글·노출·클릭·전환과 같은 지표를 분석하여 마케팅, 상품 운영, 콘텐츠 운영 관점의 개선안을 도출하는 것을 목표로 합니다.

## 2. 핵심 질문

- 어떤 카테고리의 상품/콘텐츠가 상대적으로 높은 반응을 얻는가?
- 가격, 리뷰 수, 평점, 키워드, 카테고리 등의 요인이 성과와 어떤 관계를 갖는가?
- 긍정/부정 리뷰 또는 댓글에서 반복적으로 나타나는 요인은 무엇인가?
- 성과가 높은 상품/콘텐츠와 낮은 상품/콘텐츠는 어떤 차이가 있는가?
- 개선이 필요한 세그먼트에는 어떤 액션 아이템을 제안할 수 있는가?

## 3. 예정 데이터

- 커머스 상품 데이터 또는 콘텐츠 데이터
- 카테고리 정보
- 가격 또는 순위 정보
- 리뷰/댓글 텍스트
- 평점 또는 반응 지표
- 가능하다면 노출, 클릭, 전환 유사 지표

## 4. 예정 분석 과정

### 4.1 데이터 수집 및 전처리

- 상품/콘텐츠 데이터 수집
- 결측치, 중복값, 이상값 확인
- 분석 단위 정의
- 카테고리 및 텍스트 데이터 정리

### 4.2 KPI 정의

- 성과 지표 정의
- 카테고리별 비교 기준 설정
- 리뷰/댓글 기반 반응 지표 설계

### 4.3 세그먼트 분석

- 카테고리별 성과 비교
- 가격대별 성과 비교
- 리뷰 수/평점/키워드별 반응 차이 분석

### 4.4 텍스트 분석

- 리뷰 또는 댓글 전처리
- 주요 키워드 추출
- 긍정/부정 반응 요인 분석

### 4.5 시각화 및 액션 아이템 도출

- 핵심 지표 대시보드 구성
- 성과 차이에 대한 인사이트 정리
- 마케팅/상품/콘텐츠 운영 개선안 제안
- 후속 A/B 테스트 아이디어 제안
