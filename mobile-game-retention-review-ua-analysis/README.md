# Mobile Game Retention Review UA Analysis

Cookie Cats A/B 테스트 데이터, Google Play 게임 리뷰 데이터, 보조 UA 캠페인 데이터를 활용해 모바일 게임의 리텐션 변화, 사용자 경험 신호, UA 성과 판단 구조를 분석한 프로젝트입니다.

> 본 저장소에는 공개 가능한 분석 요약과 재현 가능한 구조를 중심으로 정리했습니다. Google Play 리뷰 원문 전체, 대용량 원본 데이터, 로컬 실행 산출물은 포함하지 않습니다.

---

## 1. 프로젝트 목적

모바일 게임 서비스에서는 신규 유저 유입 이후 초기 리텐션, 리뷰에 드러나는 UX 문제, 캠페인 성과 지표를 함께 확인해야 합니다.

이 프로젝트는 다음 질문을 중심으로 구성했습니다.

1. 게임 내 게이트 위치 변경은 D1·D7 리텐션에 차이를 만드는가?
2. Google Play 리뷰에는 어떤 불만·오류·반복성 신호가 나타나는가?
3. UA 캠페인 성과는 CTR, CVR, CPI, D7 ROAS 관점에서 어떻게 비교할 수 있는가?
4. 초기 KPI만으로 D7 ROAS를 예측할 때 어떤 오차가 발생하는가?

---

## 2. 사용 데이터

| 데이터 | 설명 | 공개 범위 |
|---|---|---|
| Cookie Cats A/B Test | 게이트 위치별 유저 리텐션 데이터 | 공개 데이터셋 기반 분석 |
| Google Play Reviews | 모바일 게임 리뷰 수집 데이터 | 원문 전체 비공개, 요약 결과 중심 공개 |
| UA Campaign Dataset | 캠페인 성과 분석 구조를 재현하기 위한 보조 데이터 | 공개 가능한 요약 산출물 중심 공개 |

---

## 3. 분석 과정

### 3.1 A/B Test Retention Analysis

- 게이트 위치별 유저 수, D1 Retention, D7 Retention 비교
- 그룹 간 리텐션 차이 검정
- 실험 결과 해석 시 통계적 유의성과 서비스적 해석을 구분

### 3.2 Review Signal Analysis

- Google Play 리뷰 수집
- 리뷰 텍스트 정제
- 광고 불만, 오류, 반복성, 난이도, 과금, 콘텐츠 부족 등 리뷰 신호 분류
- 평점과 리뷰 신호를 결합해 UX 리스크 후보 정리

### 3.3 UA Campaign KPI Analysis

- CTR, CVR, CPI, D7 ROAS 등 캠페인 KPI 산출
- Campaign Performance Score 설계
- 예산 확대, 유지, 점검 후보 캠페인 분류

### 3.4 D7 ROAS Prediction Check

- 초기 KPI 기반 D7 ROAS 예측 모델 구성
- 예측 오차가 큰 캠페인 확인
- 단순 성과 예측이 아니라 캠페인 점검 후보를 찾는 용도로 해석

---

## 4. 주요 결과 요약

- A/B 테스트 데이터에서 게이트 위치에 따른 D1·D7 Retention 차이를 비교했습니다.
- 리뷰 텍스트를 UX 리스크 신호로 구조화해 사용자 불만 후보를 정리했습니다.
- 캠페인 KPI를 CTR, CVR, CPI, D7 ROAS 관점에서 비교하고 성과 점수화 구조를 만들었습니다.
- D7 ROAS 예측 오차를 통해 단순 예측값보다 점검이 필요한 캠페인 후보를 구분했습니다.

## 6. 한계 및 개선 방향

- Google Play 리뷰는 전체 유저를 대표하는 데이터가 아니며, 리뷰 작성자 편향이 존재합니다.
- 보조 UA 캠페인 데이터는 실제 회사 내부 광고 데이터가 아니므로 성과 수치를 일반화할 수 없습니다.
- 리뷰 신호 분류는 사전 기반 방식이므로 문맥, 반어, 복합 불만을 완전히 반영하지 못합니다.
- 실제 서비스 로그, 결제 데이터, 코호트별 유입 채널 데이터가 결합되면 분석 정확도를 높일 수 있습니다.
