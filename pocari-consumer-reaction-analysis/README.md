# 포카리스웨트 공개 검색 데이터 수집 및 소비자 반응 분석

## 1. 프로젝트 개요

동아오츠카 포카리스웨트 관련 네이버 블로그 공개 검색 데이터를 수집해, 소비자가 어떤 상황에서 제품을 언급하고 어떤 제품 반응 신호를 남기는지 탐색한 미니 프로젝트입니다.

단순 검색 결과 수집에 그치지 않고, **검색결과 카드 기반의 넓은 탐색**과 **상세 게시글 본문 샘플 기반의 보조 심화 분석**을 분리했습니다. 이를 통해 공개 웹 데이터 수집, 텍스트 정제, 사전 기반 다중 라벨링, 제품/비교군 분류, CX·마케팅 Action Item 도출 흐름을 구성했습니다.

> 공개 포트폴리오용 저장소이므로 전체 블로그 본문 raw 데이터는 포함하지 않았습니다. 공개 가능한 집계 결과와 분석 요약 중심으로 정리했습니다.

## 2. 분석 질문

1. 포카리스웨트는 어떤 사용 맥락에서 자주 언급되는가?
2. 일반 포카리스웨트와 제로·저당·칼로리 관심 맥락은 어떤 반응 신호가 다른가?
3. 맛, 가격, 당/칼로리, 기능감, 대체재 비교, 구매 채널 등 CX/마케팅 신호는 어떻게 나타나는가?
4. 공개 검색 데이터를 바탕으로 어떤 후속 검증 지표와 Action Item을 제안할 수 있는가?

## 4. 데이터 처리 및 보정

### 날짜 수집 개선

초기 수집에서는 검색결과 작성일이 제대로 잡히지 않았습니다. 검색결과 HTML을 직접 확인한 결과 작성일이 `sds-comps-profile-info-subtext` 계열 태그에 들어 있는 것을 확인했고, 해당 구조에 맞게 파서를 수정했습니다. 최종 데이터에서는 검색결과 카드 기준 작성일이 566건 수집되었습니다.

### 제품 타입 재분류

초기 분류는 검색어 query의 영향을 받아, 실제 본문에 포카리스웨트가 없는 글도 포카리스웨트 제로 맥락으로 분류될 수 있었습니다. 최종본에서는 query가 아니라 **실제 수집 텍스트**를 기준으로 `product_type_clean`을 다시 생성했습니다.

## 5. 라벨링 프레임

사전 기반 다중 라벨링을 사용했습니다. 하나의 게시글은 여러 라벨을 동시에 가질 수 있습니다.

| 축 | 라벨 |
|---|---|
| 사용 맥락 | 운동/러닝/헬스, 더위/갈증/수분보충, 감기/몸살/컨디션 회복, 숙취/해장, 어린이/가족, 일상 음료, 제로/저당/다이어트 |
| 제품 반응 | 맛, 가격, 용량/패키지, 당/칼로리, 기능감/효과, 브랜드 신뢰, 대체재 비교 |
| CX/마케팅 신호 | 구매 계기, 재구매/추천, 불만/개선점, 캠페인/광고 언급, 편의점/채널 언급 |

## 6. 주요 결과 요약

### 포카리스웨트 직접 언급 데이터 기준 상위 신호

| 구분 | 상위 신호 |
|---|---|
| 사용 맥락 | 운동/러닝/헬스, 더위/갈증/수분보충, 감기/몸살/컨디션 회복, 제로/저당/다이어트, 일상 음료 |
| 제품 반응 | 기능감/효과, 당/칼로리, 용량/패키지, 맛, 대체재 비교 |
| CX/마케팅 신호 | 재구매/추천, 구매 계기, 편의점/채널 언급, 불만/개선점, 캠페인/광고 언급 |

### 제품 타입별 차이

- **포카리스웨트 직접 언급 - 일반**: 기능감/효과, 용량/패키지, 맛 신호가 상대적으로 두드러졌습니다.
- **포카리스웨트 직접 언급 - 제로/저당/칼로리 관심**: 당/칼로리, 용량/패키지, 기능감/효과 신호가 상위에 나타났습니다.

일반 포카리스웨트는 운동, 수분보충, 컨디션 회복처럼 기능적 섭취 맥락과 함께 등장하는 경우가 많았습니다. 반면 제로·저당·칼로리 관심 맥락은 맛과 당/칼로리, 대체재 비교 신호가 함께 나타나며 제품 선택 기준이 더 명시적으로 드러나는 경향이 있었습니다.

## 7. CX/마케팅 Action Item 제안

1. **제로 제품 메시지는 ‘칼로리 없음’만 강조하지 말고 맛/청량감 검증 메시지와 함께 제시**
   - 제로·저당·칼로리 관심 맥락에서는 당/칼로리와 맛 신호가 함께 등장했습니다.

2. **운동/러닝 맥락에서는 수분보충·전해질·휴대성을 묶은 콘텐츠 구성**
   - 러닝, 헬스, 등산 등 활동 맥락에서 포카리스웨트가 반복적으로 언급되었습니다.

3. **컨디션 회복 맥락은 의학적 효능 단정 없이 ‘상황별 수분보충’ 맥락으로 관리**
   - 숙취, 감기, 장염 등 컨디션 회복 관련 언급은 존재하지만 치료 효과로 단정해서는 안 됩니다.

4. **대체재 비교군은 포지셔닝 점검용으로 분리 관리**
   - 이온음료 추천, 경쟁 브랜드, 전해질 음료 관련 데이터는 포카리스웨트 직접 반응과 분리해 추적하는 것이 적절합니다.

## 8. 한계

- 본 분석은 네이버 블로그 공개 검색 결과와 일부 상세 게시글 본문을 활용한 탐색 분석입니다.
- 검색 결과 노출 구조와 블로그 작성자 특성의 영향을 받으므로 전체 소비자를 대표한다고 볼 수 없습니다.
- 상세 본문 데이터는 일부 샘플에 한정되므로 정량 분포 해석보다 맥락 보강용으로 해석해야 합니다.
- 실제 구매, 매출, 재구매, 전환 데이터가 아니므로 구매 전환 요인을 단정할 수 없습니다.
- 사전 기반 라벨링 방식이므로 문맥, 반어, 미등록 표현을 완전히 반영하지 못합니다.

## 9. 이력서용 요약

> 네이버 블로그 공개 검색결과와 일부 상세 게시글 본문을 Selenium·BeautifulSoup으로 수집하고, 실제 텍스트 기준 제품/비교군 재분류 및 사전 기반 다중 라벨링을 통해 포카리스웨트의 사용 맥락, 제품 반응, CX/마케팅 신호를 분석했습니다.
