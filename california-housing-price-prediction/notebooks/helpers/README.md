# helpers

수업 과정에서 직접 학습하고 작성한 개인 분석 모듈입니다.

- `my_qtcheck`: 데이터 품질 점검과 기술통계
- `my_plot`: 분석 시각화
- `my_stats`: 통계검정과 상관·분산분석
- `my_prep`: 변환·라벨링·스케일링
- `my_ml`: 전처리 파이프라인, 모델 비교, 과적합 진단, Feature Importance, SHAP
- `my_cluster`: KMeans·계층적 군집·DBSCAN

노트북을 어느 위치에서 열어도 폰트를 찾도록 `__init__.py`의 폰트 경로만 모듈 파일 기준으로 정리했습니다.
