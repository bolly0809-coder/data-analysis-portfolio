# Dictionary-based Text Mapping Limitations

사전 기반 리뷰 텍스트 매핑 방식의 장점과 한계를 정리합니다.

## 장점

- 어떤 키워드가 어떤 카테고리에 매핑됐는지 설명 가능함
- 도메인 지식이 반영된 분류 기준을 만들 수 있음
- 모델 학습 데이터가 부족한 상황에서도 적용 가능함
- 기업별 리뷰 신호를 비교 가능한 테이블로 구조화할 수 있음

## 한계

- 사전에 없는 표현은 매칭되지 않을 수 있음
- 비꼼, 반어, 문맥 반전 표현을 완벽히 처리하기 어려움
- 하나의 문장에 긍정과 부정이 동시에 들어갈 때 세밀한 극성 분리가 어려움
- 단어가 등장했다고 해서 항상 해당 카테고리의 강한 신호라고 볼 수는 없음
- 사전 품질에 따라 커버리지와 정확도가 달라짐

## 해석 원칙

이 결과는 기업 평가를 자동 확정하는 지표가 아니라, 리뷰 텍스트에 반복적으로 등장하는 신호를 구조화한 보조 지표로 해석해야 합니다.

따라서 최종 추천/비추천 판단에는 리뷰 카테고리 신호뿐 아니라 채용공고 조건, 사용자 선호, 리뷰 수 신뢰도, 최신성, 도메인별 가중치 등을 함께 고려해야 합니다.
