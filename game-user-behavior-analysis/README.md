# Game / App User Behavior Analysis

앱 또는 게임 유저 행동 로그 데이터를 기반으로 퍼널, 리텐션, 이탈 구간, 핵심 이벤트를 분석하고 서비스 개선을 위한 가설과 A/B 테스트 아이디어를 제안하는 개인 미니 프로젝트입니다.

> 본 프로젝트는 데이터 분석가 지원을 위한 개인 미니 프로젝트로 준비 예정입니다.  
> 기어세컨드, 당근, 미리디 등 서비스/프로덕트/사용자 행동 분석 직무에 대응하기 위한 포트폴리오로 구성할 예정입니다.

## 1. 프로젝트 목표

앱 또는 게임 유저 행동 로그 데이터를 분석하여 사용자가 어느 단계에서 이탈하는지, 어떤 행동이 재방문이나 전환과 연결되는지 파악합니다.

분석 결과를 바탕으로 서비스 개선 가설과 A/B 테스트 아이디어를 제안하는 것을 목표로 합니다.

## 2. 핵심 질문

- 유저는 어떤 경로로 핵심 행동에 도달하는가?
- 가장 큰 이탈이 발생하는 단계는 어디인가?
- 튜토리얼, 가입, 첫 구매, 재방문 등 핵심 이벤트의 전환율은 어떻게 다른가?
- 유지율이 높은 유저와 낮은 유저는 어떤 행동 차이를 보이는가?
- 어떤 개선 실험을 설계할 수 있는가?

## 3. 예정 데이터

- 앱 또는 게임 유저 이벤트 로그 데이터
- 유저 ID
- 이벤트명
- 이벤트 발생 시각
- 세션 정보
- 스테이지/레벨/화면 정보
- 구매 또는 전환 여부
- 재방문 여부

## 4. 예정 분석 과정

### 4.1 로그 데이터 구조 파악

- 이벤트 로그 스키마 확인
- 유저 단위, 세션 단위, 이벤트 단위 분석 기준 정의
- 주요 이벤트 정의

### 4.2 퍼널 분석

- 가입 → 튜토리얼 → 핵심 행동 → 전환 흐름 정의
- 단계별 전환율 계산
- 주요 이탈 구간 도출

### 4.3 리텐션 분석

- D1, D7 등 재방문율 산출
- 유저 코호트별 리텐션 비교
- 고리텐션 유저와 저리텐션 유저의 행동 차이 분석

### 4.4 세그먼트 분석

- 유저 행동 패턴별 세그먼트 구분
- 전환 유저와 미전환 유저 비교
- 이탈 유저와 잔존 유저 비교

### 4.5 개선 가설 및 실험 설계

- 이탈 구간 개선 가설 제안
- 핵심 행동 유도 방안 제안
- A/B 테스트 설계안 제안
